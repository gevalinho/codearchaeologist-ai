# Architecture demo acceptance run

These browser steps are **manual acceptance steps**. They are not part of the automated Vitest suite. Use the committed synthetic artifact at `tests/fixtures/architecture/demo-graph.json`; never use a private graph for screenshots or shared recordings.

1. Run `npm run dev` and open `/`. Confirm the empty state explains local JSON import and shows no feature or preview launcher before import.
2. Click **Import graph JSON** and select `tests/fixtures/architecture/demo-graph.json`. Confirm a snapshot summary, graph viewport, Student Promotion feature workspace, and **Preview App** launcher appear. Confirm no graph upload request in the browser Network panel.
3. Click **Inspect Student Promotion** in the guidance strip. Confirm the graph focuses recorded components and the Evidence Inspector shows a relative source reference when a node or edge is selected.
4. Switch among **Legacy**, **Modern**, and **Compare**. Confirm Legacy distinguishes observed and inferred edges, Modern labels components as recommendations, and Compare shows source references beside proposed placements.
5. Zoom and drag the graph, then use **Fit view**. Confirm all nodes in the focused view are reachable and selection still works.
   Confirm long method and path labels remain inside node boxes, the full name is available by selecting the node, and long source references wrap in the Evidence Inspector. Repeat at desktop, tablet, and mobile widths; check that graph controls and the preview launcher remain reachable.
6. Open **Preview App** from the launcher or the Preview perspective. Confirm the right drawer opens with a backdrop, the feature title and proposal indicator, and the architecture workspace remains visible behind it on desktop.
7. Choose **Demo Year A**, **Demo Class 1** as source, and **Demo Class 2** as destination. Select **Demo Learner 01** and **Demo Learner 02**. Confirm the selected count and summary update. Change the source class and confirm selection clears; then restore the source class and reselect a learner.
8. Click **Review proposed batch**. Confirm the review screen shows only demonstration choices. Click **Simulate confirmation** and confirm the completion state says no records were changed. The Network panel should show no mutation request from these actions.
9. Close the drawer, reopen it, and confirm the completion state and selections remain. Click **Reset demo** or **Start a new demonstration** and confirm all selections and fields clear.
10. Open the drawer again with keyboard focus on its launcher. Confirm focus moves inside the dialog. Press Tab and Shift+Tab through controls and confirm focus does not leave the drawer. Press Escape and confirm focus returns to the launcher or opening action.
11. Reopen the drawer; test backdrop close and the expand/collapse control. Confirm body scrolling is locked while open and restored after close. Confirm the drawer content scrolls independently and **Architecture Trace** expands to show proposal responsibilities, available legacy references, certainty, and verification gaps.
12. Resize to a narrow mobile viewport. Confirm the drawer occupies the full width, controls remain usable, the learner table scrolls horizontally, and the close button remains visible.
13. Close the drawer and confirm the previous graph selection, pan/zoom, and Legacy/Modern/Compare selection remain intact. Import a new artifact and confirm the previous demonstration state is discarded.
14. Check the browser console for application and hydration errors. If a hydration warning appears, repeat in a clean browser profile with extensions disabled and compare the DOM changes before attributing the warning to the app.

For browser directory scanning, choose **New Investigation → Scan local repository directory** with a disposable synthetic repository. Confirm the folder picker appears, the progress steps advance, the graph and module candidates load automatically, and both downloads parse as JSON with matching snapshot IDs. Cancel a second scan, then import `tests/fixtures/architecture/demo-graph.json` and confirm the existing import still works. Inspect Network requests to confirm selected source bytes are not uploaded. Browser symlink behavior and narrow-screen layout require manual review.

For a large WSL-hosted repository, open Chrome DevTools before selecting the folder. Run `monitorEvents(document.querySelector('input[aria-label="Select local repository directory"]'), ['change', 'cancel'])` in the Console. Click **New Investigation → Scan local repository directory**, choose the folder, and click **Upload**. If the native dialog is still enumerating, no `change` event or received-file count is available; the page's waiting message explains this. Once `change` appears, confirm the repository name and exact received count appear immediately, then the validating, reading, extracting, validating-artifact, and ready steps. Compare eligible and processed counts with the CLI's source-file count; note that malformed/binary files may be skipped. Confirm the UI stays responsive, **Cancel scan** stops a second run, oversized selections show a limit error, and no source-upload request appears in Network. Turn off `monitorEvents` afterward with `unmonitorEvents(document.querySelector('input[aria-label="Select local repository directory"]'))`.

Route smoke check: open `/` and confirm the Repository Intelligence heading and both investigation entry points. Open `/architecture` in a fresh tab and confirm the address changes to `/` while the same workspace appears. Open `/examples/legacy-pricing` and confirm the pricing fixture, **Run AI investigation**, and **Load local report** are present; use its Repository Intelligence link to return home. The paid investigation action remains opt-in and must not be clicked during this read-only route check.

Automated model tests cover artifact validation, discovery, graph traversal, blueprint and preview references, demonstration state, drawer visibility, and focus target calculations. They do not exercise real browser layout, focus movement, or hydration.
